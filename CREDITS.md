# Credits

## The riffs
The five riff building blocks (Quick Dip, Swift Lift, Swoopy Swift Lift, Quick Dip Trip, Skip Quick Dip Trip), their names, and the combinations come from Crystal Cherelle of Indie Artist School:

- Video: [Master 5 R&B Riffs Every Pro Singer Uses | Building Block Method](https://www.youtube.com/watch?v=saWqsqZUy5M)
- Her interactive tool: [Riff Builder](https://riffbuilder.indieartistschool.com)
- Coaching and courses: [indieartistschool.com](https://indieartistschool.com)

This project is a personal practice tool built around her lesson. If you like the method, go learn it from her.
